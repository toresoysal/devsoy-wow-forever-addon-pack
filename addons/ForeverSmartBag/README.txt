Forever Smart Bag · Devsoy · 1.0.1
==================================

One bag window, items grouped by type: quest items, potions/food/bandages,
equipment, trade goods, recipes, bags and ammo, other, junk (gray), empty slots.
Slots are Blizzard's own bag buttons: right-click to use or sell, drag and drop,
shift-click to split. Search box and Clean Up Bags work like the default bag.

Install
- Unzip and put the ForeverSmartBag folder into World of Warcraft\_forever_\Interface\AddOns\
- Restart the game fully. Make sure it is ticked in the AddOns list on the character screen.

Use
- B opens/closes the bag. It opens by itself at a vendor. Escape closes it.
- Drag the title to move it; the position is saved.
- /sb  toggle  ·  /sb cols 12  width (4-20)  ·  /sb blizzard  give the B key back to the Blizzard bag / take it again
