Forever Diablo UI · Devsoy · 1.0.0
==================================

Action bars and health/mana orbs with a Diablo feel.
- Square 3D action bars: three rows in the middle of the screen, two columns on the right.
  Blizzard's own buttons, so key bindings and page switching work as usual.
- Cooldown numbers, blue edge without mana, red edge out of range, a heartbeat when a
  cooldown ends.
- Diablo-style health and mana orbs (liquid, bubbles, surface wave), XP bar, an aurora
  in your class colour.
- Pick a button frame: Iron corners, Stone slot, Silver filigree, No frame.
- Optional dark ring around the orbs.
- Size and visibility: bar size, orb size, visibility out of combat and in combat.

Install
- Unzip and put the ForeverDiabloUI folder into World of Warcraft\_forever_\Interface\AddOns\
- Restart the game fully. Make sure it is ticked in the AddOns list on the character screen.

Commands
- /dui options     settings window
- /dui frame       change the button frame         /dui ring    orb ring on/off
- /dui scale 1.2   bar size (0.6-1.6)              /dui orbs 1.1  orb size (0.5-1.5)
- /dui alpha 0.8   visibility out of combat        /dui fight 1   visibility in combat
- /dui move        move the bars (lock/unlock)     /dui keys     key bindings
- /dui pages       page lock (Shift+2-6 and Shift+wheel)

The cast bar and DoT warning are not in this addon: FelCast. Unit cards are in SoulLedger.
The Turkish version is a separate addon: Forever Diablo Arayüz. If both are installed, only one runs.
